# TypeFlow — Typing Speed Tester

TypeFlow is a beautiful, responsive typing speed test built with HTML, CSS, and vanilla JavaScript.

## Features
- 15, 30, 60, and 120-second typing modes
- Live WPM, accuracy, timer, and best-score tracking
- Word-by-word highlighting
- Correct, incorrect, and extra-character indicators
- Blinking caret
- Custom typing sounds: Soft Click, Mechanical, Typewriter, and Bubble
- Volume control
- LocalStorage best-score saving
- Fully responsive dark UI

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Web Audio API
- LocalStorage

## How to Run
1. Clone the repository
2. Open `index.html` in your browser

## Controls
- Start typing to begin
- Press `Tab` to restart
- Choose a sound from the top-right menu
